Таблички

<caption> — НАЗВАНИЕ ТАБЛИЦЫ
<thead> → <tr> → <th> (Ячейка-заголовок 1) <thead> → <tr> → <th> (Ячейка-заголовок 2)
<tbody> → <tr> → <td> (Строка 1, ячейка 1) <tbody> → <tr> → <td> (Строка 1, ячейка 2)
<tbody> → <tr> → <td> (Строка 2, ячейка 1) <tbody> → <tr> → <td> (Строка 2, ячейка 2)
<tfoot> → <tr> → <td> (Итог 1) <tfoot> → <tr> → <td> (Итог 2)

Формат записи:

<table>
  <caption>Название таблицы</caption>
  
  <thead>
    <tr>
      <th>Ячейка-заголовок 1</th>
      <th>Ячейка-заголовок 2</th>
    </tr>
  </thead>
  
  <tbody>
    <tr>
      <td>Строка 1, ячейка 1</td>
      <td>Строка 1, ячейка 2</td>
    </tr>
    <tr>
      <td>Строка 2, ячейка 1</td>
      <td>Строка 2, ячейка 2</td>
    </tr>
  </tbody>
  
  <tfoot>
    <tr>
      <td>Итог 1</td>
      <td>Итог 2</td>
    </tr>
  </tfoot>
</table>

Подключение с сайта:

Генерируем ссылку на сайте: https://google.com

Вставляем:

<head>
  <link href="https://googleapis.com.." rel="stylesheet">
</head>

Подключение из файла (в CSS):

@font-face {
  font-family: 'MyCustomFont'; /* 1. Придумываем любое имя для шрифта */
  src: url('fonts/MyFont.woff2') format('woff2'), /* 2. Основной современный формат */
       url('fonts/MyFont.woff') format('woff');   /* 3. Запасной для старых браузеров */
  
  font-weight: normal; /* Насыщенность (normal, bold или цифры 400, 700) */
  font-style: normal;  /* Стиль (normal или italic) */
  font-display: swap;  /* Чтобы текст не исчезал, пока шрифт скачивается */
}

Семантический HTML

Тег Назначение блока Пример использования Важное правило / Особенность
<header> Шапка сайта, текущего раздела или отдельной статьи. 
<header>
  <img src="logo.png" alt="Лого">
  <h1>Название блога</h1>
</header>
 Может встречаться на странице несколько раз (в начале всей страницы и внутри тегов <article>).
<nav> Главный блок с навигационными ссылками. 
<nav>
  <a href="/">Главная</a>
  <a href="/catalog">Каталог</a>
</nav>
 Используется для основных меню, пагинации и хлебных крошек. Одиночные ссылки в тексте оборачивать не нужно.
<main> Главное, уникальное содержимое конкретной страницы. 
<main>
  <h1>Каталог товаров</h1>
  <!-- Основной контент -->
</main>
 Строго один на странице. Нельзя вкладывать внутрь <header>, <footer> или <aside>.
<section> Крупный смысловой раздел документа. 
<section>
  <h2>Наши услуги</h2>
  <p>Описание услуг...</p>
</section>
 Каждая секция должна содержать собственный заголовок (h2-h6). Не используйте элемент просто как обертку для стилей.
<article> Автономный, независимый блок информации. 
<article>
  <h2>Новость дня</h2>
  <p>Текст новости...</p>
</article>
 Подходит для постов, комментариев или карточек товаров, которые можно без потери смысла перенести на другой ресурс.
<aside> Дополнительный контент, косвенно связанный с основным. 
<aside>
  <h3>Популярное</h3>
  <ul>...</ul>
</aside>
 Используется для сайдбаров, блоков рекламы, виджетов или списков похожих материалов.
<footer> Подвал сайта, раздела или отдельной статьи. 
<footer>
  <p>&copy; 2026 Моя Компания</p>
</footer>
 Обычно содержит информацию об авторе, копирайты, контакты и ссылки на юридические документы.
<figure> Самодостаточный медиа-контент (фото, схемы, куски кода). 
<figure>
  <img src="chart.png" alt="Схема">
  <figcaption>Рис. 1 — График</figcaption>
</figure>
 Если убрать этот блок в конец страницы, основной текст не должен потерять логический смысл.
<figcaption> Подпись или заголовок для содержимого <figure>. См. пример выше для <figure> Должен располагаться первым или самым последним элементом внутри <figure>.
<time> Машиночитаемая дата и время. 
<p>Опубликовано 
  <time datetime="2026-07-29">сегодня</time>
</p>
 Атрибут datetime передает точную дату поисковикам, а текст внутри тега виден пользователям.
<address> Контактная информация автора или организации. 
<address>
  Пишите на <a href="mailto:i@site.com">i@site.com</a>.
  г. Москва, ул. Ленина 1
</address>
 Не используйте для произвольных почтовых адресов, которые не связаны напрямую с контактами владельцев страницы.
<mark> Текст, выделенный для привлечения внимания (как маркером). 
<p>Акция: скидки 
  <mark>до 70%</mark> только в июле!
</p>
 По умолчанию браузеры подсвечивают этот текст ярким желтым фоном.
<details> Интерактивный раскрывающийся блок (аккордеон/спойлер). 
<details>
  <summary>Частые вопросы</summary>
  <p>Ответ на ваш вопрос...</p>
</details>
 Работает стандартными средствами HTML без единой строчки JavaScript. Открытое состояние задается атрибутом open.
<summary> Заголовок раскрывающегося блока <details>. См. пример выше для <details> По клику на него скрытая часть <details> разворачивается или сворачивается.
